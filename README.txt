COZY COFFEE WEBSITE
Open index.html in your browser.
All pages use the same top hero background image (images/home-background.png): Home, About, Menu, Contact and Cart.
Menu items have local photos, sample EGP prices and Add to Cart buttons.
Cart supports quantity changes, removal and subtotal/total using localStorage.
Checkout and contact form are front-end demos and do not submit real orders/messages.
Built with HTML, CSS and simple JavaScript.
